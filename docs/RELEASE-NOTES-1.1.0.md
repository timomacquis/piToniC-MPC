# πToniC 1.1.0

A Microtonic-inspired drum machine.

- New **EXTENDED** effects, from πMorpH 0.2.0: Tidal Verb (10 reverb types, Decay, Liveliness, Warmth) and the Dub Station delay (7 tempo divisions or 10–2,000 ms, feedback up to 120%, LP/HP filter). One button on the EFFECTS page switches between them and the original effects; sends, ON and RETURN are shared.
- Existing presets, projects and the 150 Patternarium BEST kits open with EXTENDED off and sound bit-identical to 1.0.4 (checked by an automated comparison with the previous engine). New instances start with EXTENDED on.
- Every Q-Link now drives a control shown on its page (NOISE, CHARACTER, EFFECTS). In the original delay, TIME is now a dial in SYNC too.
- One release zip for Gen1 (ARM32) and Gen2 (ARM64), in the Akai SDK folder format.

Credits: Tidal Verb (Fullban), Dub Station (nachtaktiv303), CHOMPI DSP (CHOMPI Club), DaisySP (Electrosmith), all MIT; licences included.

Gen1 ARMv7 tested by the author on Force. The Gen2 ARM64 binary is compiled and package-checked on PC only; not tested on Gen2 hardware.
