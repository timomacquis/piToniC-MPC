# πToniC 1.0.1

Add a SAMPLE source to each of the eight percussion voices.

- Switch each voice between SYNTH and SAMPLE.
- Load mono/stereo WAV files up to ten seconds: PCM 16/24/32-bit or float32, 8–192 kHz.
- TUNE adjusts playback pitch; START chooses the start position. Envelopes, pitch modulation, noise, character processing and effect sends remain available.
- Contextual TONE Q-Links change from FREQUENCY / WAVE MORPH to TUNE / START.
- Background sample loading and cached positive/negative waveform peaks.
- Clearer sample browser, aligned SOURCE / LOAD controls and updated illustrated manuals.
- Preserve the 150 native Patternarium BEST kit presets.

Projects and presets store original sample paths; audio is not embedded or collected beside the preset. Keep files at their original locations. No time-stretch or sample loop is provided. Older binaries cannot read the sample-state extension; retain original project copies.

Gen1 ARMv7 / Force package, MPC OS 3.x. This release does not add an ARM64 Gen2 port. The author validated the candidate in a musical session on Force OS 3.10.0.49; a formal install/uninstall test of this exact release package is not newly claimed.
