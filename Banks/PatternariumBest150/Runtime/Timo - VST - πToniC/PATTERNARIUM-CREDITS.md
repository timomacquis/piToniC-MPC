# Preset source credits

150 kits selected from the Best of Generation 4–28 folders of the Patternarium archive supplied by Greg. Original generated sounds: Sonic Charge / Patternarium, for Microtonic. Converted parameter recipes, not the Microtonic DSP. Factory Microtonic presets are not part of this bank. All original filenames, generations and hashes are retained in SELECTION.json.

Source-use references: https://soniccharge.com/forum/topic/1336 (Patternarium description and public-domain statement, 2019) and https://soniccharge.com/forum/topic/2562-selling-sample-packs-made-with-sonic-charge-plugins (2023 statement about informing Sonic Charge and attribution for Patternarium use in sample packs). No publisher correspondence or separate permission is claimed here. Keep these source credits with the bank.
